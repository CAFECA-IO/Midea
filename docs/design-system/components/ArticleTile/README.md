# ArticleTile

首頁「今日報導」與 /news 的一篇報導，放在 `BentoGrid row="hero"`。

- 頭條 `cols=2 rows=2`：放完整的寬版圖（`figure` 傳 SVG 字串）與 `dek`；其餘 1×1 放 300×130 的縮圖（伺服器的 `mini`）。
- 頂端：`KindChip` ＋來源名稱；`badge` 可放 `InfluenceTag`（「讀者想看的續作」）。
- `meta`：「想看續作 n / 20」與「做成影片 n」或「影片製作中 · 編輯選」。
- 5 篇：頭條 2×2 ＋ 4 個 1×1；4 篇：最後一篇 2×1；3 篇：兩篇 2×1；2 篇：各 2×2。一列不留空格。
- `figure` 只接受伺服器產生、文字已跳脫的 SVG。
- 有封面 `image` 時：頭條整塊是封面＋`scrim`，文字在影像上（`on-image`）；1×1 上方 46% 是封面、下方是標題與進度。沒有封面才用圖表縮圖。
