# VideoTile

影像磚：劇照鋪滿、底部 `scrim` 遮罩、文字疊在上面。

- `size="hero"`：直播主磚，2×2，片名用 46px；放 `badge`（現正播放）與 `action`（`light` 按鈕）。一頁只有一個。
- `size="md"`：主題主打與排行以外的 2×2，片名 20px。
- `size="sm"`（預設）：1×1 或直式 1×2，片名 15px，一行放不下就省略號。
- `eyebrow` 放時間或類別（「下一個時段 22:00」），`subtitle` 放類型與時長。
- 人像用 `focus="top"`；`alt` 描述畫面，純裝飾可留空。
