# ArticleFigure

文章的圖。七種模板各有一種圖（長條、排行、時間軸、對照、流程、分類）；圖由伺服器依 AI 給的資料畫成 SVG，顏色用 token，跟著主題變。

- `wide`（640 單位，桌機）與 `narrow`（340 單位，手機）兩版，639px 以下自動換，字不會縮到看不清楚。
- 標記（長條、節點、方塊）可點、可用鍵盤 Enter；`onSelect(i)` 回傳索引，`selected` 由外部指定（數據故事用段落帶動）。
- `caption` 可以是字串或 `(selected) => node`，寫「點長條看數字」這類說明。
- `compact` 拿掉外框底色，放在卡片裡用。
