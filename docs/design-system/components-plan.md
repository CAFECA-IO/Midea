# 元件規劃

元件分兩批：**已完成**的在 `window.Midea`，有即時預覽與使用說明；**規劃中**的列出用途、主要資料與優先順序（P1 = 首頁上線前、P2 = 上線後第一個月、P3 = 之後）。新增元件一律先用現有 token，不新增顏色。

| 群組 | 元件 | 用途 |
|---|---|---|

## 規劃中

### 播放

| 元件 | 用途 | 主要資料 | 優先 |
|---|---|---|---|
| `LivePlayer` | 官方頻道直播：畫面、時段名稱、第幾部、接下來 | 時段、組成影片、目前位置 | P1 |
| `VideoPlayer` | 單一影片播放：雙語字幕切換、靜音、全螢幕、章節 | 影片、字幕軌、比例 | P1 |

## 命名與 API 約定

- 元件名用英文 PascalCase；畫面文字一律由呼叫端傳入，元件不寫死中文（`SignInButton` 的預設文字除外）。
- 影像一律傳 `image`（網址）與 `alt`；人像加 `focus="top"`。
- 尺寸用 `cols`、`rows`（Bento 格數），不傳像素。
- 狀態用語意名稱：`tone="live" | "now" | "new" | "up" | "down" | "same" | "neutral"`，不傳顏色。
